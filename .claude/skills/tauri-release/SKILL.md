# Tauri release (Valet, Windows)

Verify every item against the current Tauri 2 docs (tauri.app) before applying; APIs change between minor versions. Pin versions.

## Bundling
- `bundle.targets`: `nsis` (per-user install, `installMode: currentUser`), WebView2 `installMode: downloadBootstrapper`.
- `productName: Valet`, identifier `ro.valetapp.desktop` (adjust once the domain is bought), icons generated with `pnpm tauri icon`.
- Version in one place; policy decided in Phase 3.

## Updater
- `tauri-plugin-updater` with `pubkey` in config (public key only). Private key: generated by Vlad with `pnpm tauri signer generate`, stored as GitHub Secrets `TAURI_SIGNING_PRIVATE_KEY` and `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Never in the repo.
- Two endpoints: `latest.json` on the latest release for stable; `latest-beta.json` on pre-releases for beta. The app reads the channel from settings.
- Staged rollout: beta first; stable only after 7 days without data-loss reports.

## CI (GitHub Actions)
- `ci.yml`: ubuntu + windows, clippy -D warnings, fmt, tests, pnpm build.
- `release.yml`: on tag `v*`, `tauri-apps/tauri-action` builds NSIS, signs updater artifacts, uploads to a draft release; Vlad publishes. Installer code signing via `signCommand` once a certificate exists (SignPath / Certum / OV); until then README documents the SmartScreen warning.

## Distribution
- winget: manifest under `packaging/winget/` following the `microsoft/winget-pkgs` schema; submit via `wingetcreate`.
- Microsoft Store: MSIX built with `makeappx` from the release bundle, `packaging/msix/AppxManifest.xml`, Store signs on submission. In-app Pro purchase uses Valet's own checkout (Paddle), 0% Store fee for apps.

## Rollback
- Keep the previous release assets; `latest.json` can be repointed to the previous version within minutes. Document the exact steps in `docs/RELEASE.md`.
