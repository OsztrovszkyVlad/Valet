Valet puts your files in order, on your own computer, by rules you can see and undo.

Valet is a Windows program that watches the folders you choose, for example Downloads and Desktop, and applies your rules to the files in them. No chat, no cloud, no guessing: each file goes where a rule you read says it goes.

  • Moves files by rules. A rule has conditions (extension, file type, part of the name, size, age, duplicate) and an action (move, copy, send to the Recycle Bin, or only report). There are 8 ready-made rules, for example "Downloads by type" and "Screenshots".
  • Preview before anything moves. Valet lists what it would do: file, from, to, which rule. Nothing moves until you approve. Automatic organizing starts only after you have approved a preview.
  • Undo. A batch of operations can be undone as long as the moved files have not been changed by you. If they have, Valet asks first.
  • Recycle Bin only. Valet never deletes anything permanently and never overwrites an existing file: a taken name becomes name (2).ext.

Valet is in beta. Do not point it at folders whose contents you cannot lose, and use the preview.

Download

Download from GitHub Releases

The file is Valet_<version>_x64-setup.exe. It installs for the current user only, with no administrator rights. The app has Romanian and English interfaces; Romanian is the default.

SmartScreen warning. The installer is not code-signed yet. Windows SmartScreen will show "Windows protected your PC". To go on, select More info, then Run anyway. Windows shows this for programs that are unsigned and not widely downloaded; it is not the result of an analysis of Valet. A signing certificate has not been obtained yet. If you want to check the downloaded file, compare its SHA-256 (Get-FileHash in PowerShell) with the one listed by the "Release" run in GitHub Actions.

A Microsoft Store package is being prepared and is not available yet. In the Store version, updates come through the Store, and starting with Windows is set in the Windows settings. Uninstalling the Store app deletes its data, including history and undo.

Frequently asked questions

What does Valet send over the network?

Two things, and neither contains file names, paths or file contents.

  • The check for a new version. Valet asks GitHub for a static JSON file (the address of your channel, Stable or Beta), 30 seconds after it starts and then once every 24 hours. The request has no body and does not send the installed version; GitHub sees what any web server sees, for example your IP address. Valet installs a new version only after you press a button and confirm. You can switch the automatic check off in Settings, Updates, with the checkbox "Check for updates automatically"; the button "Check now" still works.
  • The license check. Only if you have imported a Pro license, in a build with a license server configured (the current builds have none): at activation, then at most once every 30 days, when you remove the license in Settings, and when you press "Check license now". What is sent is the license id (a random code), a machine identifier that is a one-way hash, and the app version. The computer name, your email address, paths, file names, rules and rule counts are not sent. The 14-day trial and the Free plan make no license request.

No telemetry, no crash reports (there are none yet), no account, no ads. Details: the privacy page.

Does Valet delete files?

Not permanently. When a rule removes something, the file goes to the Windows Recycle Bin. On a drive without a Recycle Bin (some USB drives, network shares) Valet refuses the action and leaves the file where it is. If you empty the Recycle Bin, Valet can no longer bring that file back when you undo.

Valet does not overwrite files: if the name at the destination is taken, the file gets a new name, for example report (2).pdf. Each operation is written to a journal before it runs, and after a crash of the program or the computer, Valet checks the unfinished operations at the next start. What is tested and what is not is described in the safety document.

What happens after the 14-day trial?

If you have no Pro license, Valet falls back to Free. Nothing is deleted. Own rules beyond the 3 allowed stay saved but disabled, and you choose which 3 stay active. Watched folders beyond 2 stay in the configuration but are not watched while you are on Free; you choose which 2 folders stay active, in the same window as for the rules, and until you choose, the first 2 in the list stay active. History is not deleted; on Free it shows the batches from the last 7 days. If you move to Pro later, the rules that the limit disabled are enabled again.

Can I get my money back?

Yes, within 14 days of purchase. The refund goes through the merchant that processed the payment, not directly through Valet. When the refund is made, the license is revoked.

  • What the app does. Valet learns about the revocation at the next license check, which happens at most once every 30 days; if you press "Check license now" in Settings, Valet Pro, it happens at once. Then Valet goes back to the 14-day trial, if it has not ended, or to the Free plan. Your rules, folders, history and settings stay; whatever goes over the Free limits is switched off, not deleted.
  • The license file stays on the computer, so Settings can say why it is no longer active.
  • Buying is not open yet, so for now there is nothing to refund.
Where do I ask for help or report a problem?

On GitHub Issues. For now there is no other way to get in touch, and no email address.

Pages on GitHub Issues are public. Do not put your email address, your license file or any of your files in them. The Valet log can contain file paths if you switched on "Detailed log": read it before you paste it. If a file seems to be missing, look in the Recycle Bin and in History first.

Which Windows versions are supported?

Windows 10 22H2 and Windows 11, 64-bit. Valet uses Microsoft WebView2: Windows 11 has it installed, and the installer downloads it on Windows 10 if it is missing (the only case where the installer needs the internet). The beta has not been tried on every Windows setup yet.

Is it open source?

Yes. The code is public on GitHub under the MIT license (the LICENSE file in the repository). The Pro features are in the same program and are unlocked with a signed license file; the program itself enforces the limits of the Free plan.

Is this like Hazel?

The idea is the same: you watch folders, write rules, and the program applies actions to files. Hazel is a Mac program made by Noodlesoft; Valet is a separate program, not connected to them, and runs on Windows only. Valet cannot rename or tag files yet; it can move, copy, send to the Recycle Bin and report.
