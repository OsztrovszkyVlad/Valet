Privacy

This page says what Valet sends over the network, what it stores on your computer, what it does not have, and what happens to the data when you uninstall. It is a summary. The full text, with each statement tied to the code or test it comes from and with what was not checked, is in the repository: PRIVACY.md.

Short version. Valet makes two kinds of network request: a check for a new version of itself and, only if you have imported a Pro license, a license check. No file name, path, rule or file content is part of either. Everything else stays on your computer.

What goes over the network

The check for a new version

  • Valet makes an HTTPS GET to GitHub for a static JSON file. The address depends on the channel you choose in Settings, Updates: Stable or Beta.
  • The request has no body and no cookie. The installed version, the Windows version and the processor type are not sent. Versions are compared on your computer.
  • GitHub sees what any web server sees: your public IP address, the time and the connection data. What GitHub keeps is GitHub's.
  • When: 30 seconds after Valet starts, then once every 24 hours while Valet keeps running, and when you press "Check now".
  • An automatic check installs nothing. Installing needs a click and a confirmation.
  • The automatic check cannot be switched off in Settings; you can only choose the channel.

The license check

This part describes how the check is designed; its code is being added in this phase.

  • When: only if you have imported a Pro license. At activation, then at most once every 30 days (the app looks at startup and every 24 hours). The 14-day trial and the Free plan make no license request.
  • What is sent: the license id (a random code from the license file), a machine identifier that is a one-way hash (the first 32 characters of the blake3 hash of a fixed text and the Windows MachineGuid), and the app version. The server also sees your IP address and the time, like any web server, and remembers which machines activated a license so that it can count activations (3 at most).
  • What is never sent: file names, paths, rules or counts of rules or files, the raw MachineGuid, the computer name, the Windows version, the email address in the license.
  • Where the license is: in the app data folder, as license.valet-license, plus activation.valet-token, the server's last answer.
  • Removing the license in Settings sends a deactivate request, which frees that computer's activation. Uninstalling does not.
  • Offline: Valet keeps the token; the license stays Pro for up to 60 days after the last successful check, then the app works as Free, losing nothing, until the next successful check.
  • When it is not active: in a build without a configured license server, the app makes no license request and a Pro license cannot be activated.

Other connections

  • The installer downloads Microsoft WebView2 only if it is missing from the computer. That is the installer talking to Microsoft, not Valet.
  • WebView2 has its own update service; what it contacts is not covered here.
  • No network capture was made while Valet ran, so what Tauri and its plugins do beyond the above is read from code, not observed.

What Valet stores on your computer

  • In %APPDATA%\ro.valetapp.desktop: the database with the rules and the operation journal (the full source and destination path of every operation, sizes, content hashes of the files moved, the state of each operation), the watched folders, settings, approvals and, if you imported a license, its files. The journal is never trimmed for plan reasons.
  • In %LOCALAPPDATA%\ro.valetapp.desktop\logs: the file valet.log, at most 5 files of 2 MB. The normal log lines of Valet carry no file paths (read from the code, not tested; some operating system error texts were not checked). "Detailed log (for troubleshooting)" in Settings, off by default, can write paths. Valet never sends the logs anywhere; if you send one to someone for support, read it first.
  • Start with Windows, if you turn it on, writes a value under HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

What Valet does not have

  • No telemetry: nothing counts what you do, and there is no analytics library in the program.
  • No crash reports. A crash leaves a line in the local log and nothing else. If crash reports are added later, they will be opt-in and will show exactly what is sent.
  • No account, no advertising, no cloud copy of your rules, journal or files.

Nothing prevents a future version from adding a network call, and no test fails when one is added; if that happens, this page and the full document change.

Uninstalling

  • Your data is kept by default. The uninstaller has a checkbox "Delete the application data", unticked at the start; ticked, it removes the two folders above (so History, undo and the license files are gone).
  • Uninstalling undoes nothing: moved files stay where they are, and files in the Recycle Bin stay in the Bin.
  • The uninstaller does not contact the license server. To free the activation, remove the license in Settings first.

This site

The site is static HTML and one CSS file. It has no scripts, cookies, analytics, forms, or fonts and images from other sites. Hosting has not been chosen yet; like any host, it will see the ordinary data of a web server.
